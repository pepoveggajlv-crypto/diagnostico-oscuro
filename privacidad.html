Política de privacidad

Estudio Shorts Médicos · canal «Diagnóstico Oscuro» · Última actualización: 30 de septiembre de 2026

«Estudio Shorts Médicos» (en adelante, «la herramienta») es una aplicación de uso personal del creador del canal «Diagnóstico Oscuro». Sirve para subir los videos cortos que el propio creador produce a sus cuentas de YouTube, Facebook y TikTok. No está abierta al público y no tiene otros usuarios.

Qué datos usa

  • YouTube (Google): un token OAuth con el permiso youtube.upload para subir videos al canal del creador. Si se autoriza la lectura de estadísticas, también se usan los permisos de solo lectura de YouTube y YouTube Analytics para ver el rendimiento de los propios videos.
  • Facebook (Meta): el identificador y el token de acceso de la página del creador, con los permisos pages_show_list, pages_read_engagement y pages_manage_posts, para crear Reels en borrador.
  • TikTok: el identificador de usuario (open_id) y los tokens de acceso y renovación con los permisos user.info.basic, video.upload y, si se activa, video.publish, para enviar videos a la cuenta del creador.

La herramienta no recoge datos de espectadores, seguidores ni de ninguna otra persona.

Para qué se usan

Solo para subir los videos del creador a sus propias cuentas y, en su caso, consultar las estadísticas de esos videos. Los datos no se venden, no se comparten con terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial.

Dónde se guardan y cuánto tiempo

Los tokens se guardan cifrados como secretos del repositorio privado de GitHub del creador, o en archivos locales de su computadora. Se conservan mientras la herramienta esté en uso y se eliminan cuando el creador revoca el acceso o deja de usarla.

Cómo revocar el acceso

  • Google/YouTube: myaccount.google.com/permissions
  • Facebook: Configuración → Integraciones empresariales (facebook.com/settings?tab=business_tools)
  • TikTok: Ajustes y privacidad → Seguridad → Apps y servicios

Servicios de terceros

La herramienta usa los servicios de API de YouTube. Al usarla se aplican también los Términos del servicio de YouTube y la Política de privacidad de Google. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. También se aplican las políticas de Meta y de TikTok.

Contacto

Para cualquier duda o para pedir que se borren datos: diagnosticooscuro@gmail.com

Privacy Policy

Estudio Shorts Médicos · "Diagnóstico Oscuro" channel · Last updated: September 30, 2026

"Estudio Shorts Médicos" ("the tool") is a personal tool used only by the creator of the "Diagnóstico Oscuro" channel to upload the short videos they produce to their own YouTube, Facebook and TikTok accounts. It is not offered to the public and has no other users.

Data used

  • YouTube (Google): an OAuth token with the youtube.upload scope to upload videos to the creator's channel, and, if authorized, read-only YouTube and YouTube Analytics scopes to view the performance of the creator's own videos.
  • Facebook (Meta): the creator's Page ID and Page access token with pages_show_list, pages_read_engagement and pages_manage_posts, to create draft Reels.
  • TikTok: the user identifier (open_id) and access and refresh tokens with user.info.basic, video.upload and, if enabled, video.publish, to send videos to the creator's account.

The tool does not collect data about viewers, followers or any other person.

How data is used

Only to upload the creator's videos to the creator's own accounts and, where applicable, to read statistics for those videos. Data is never sold, shared with third parties, used for advertising, or used to train AI models.

Storage and retention

Tokens are stored encrypted as secrets in the creator's private GitHub repository, or in local files on the creator's computer. They are kept while the tool is in use and deleted when the creator revokes access or stops using the tool.

Revoking access

  • Google/YouTube: myaccount.google.com/permissions
  • Facebook: Settings → Business integrations (facebook.com/settings?tab=business_tools)
  • TikTok: Settings and privacy → Security → Apps and services

Third-party services

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The Meta and TikTok policies also apply.

Contact

For questions or data deletion requests: diagnosticooscuro@gmail.com
